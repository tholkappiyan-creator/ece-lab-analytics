 # ECE Lab - Sensor Analytics Dashboard

🚀 **Live Demo:** https://ece-lab-analytics-2bzjedjsz9mc6hrhzzwrno.streamlit.app/

ECE Sensor Analytics Dashboard using Python Streamlit.

### Features:
- Live Temperature, Humidity & Voltage Monitoring
- Temperature Over Time Graph
- Average Sensor Values Display
- Simple & Clean Dashboard UI

### Technologies Used:
- Python
- Streamlit
- Pandas

### How to Run:
pip install -r requirements.txt
streamlit run app.py
